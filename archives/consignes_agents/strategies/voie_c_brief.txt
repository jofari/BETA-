## Le portefeuille composite (avant vol-targeting)
Trois jambes, chacune produisant un vecteur de positions (fraction de capital par actif et par jour), calculees sur les donnees jusqu'a t, appliquees au rendement de t+1 (shift(1) partout). AUCUN look-ahead.

1. **Jambe base (inverse-vol)** : w_i = (1/sigma_i) / somme(1/sigma_j), sigma_i = vol realisee 180j de l'actif i.
2. **Jambe trend (TSMOM)** : pour chaque actif, m_i = signe(rendement cumule sur 126j), position proportionnelle a m_i / sigma_i (normalisee a 1/vol ; le signe porte la direction).
3. **Jambe carry (funding)** : cross-sectional. Rang par funding quotidien (somme 8h) : long les 3 funding les plus bas, short les 3 plus hauts, poids egaux.

Combine les 3 jambes a poids egaux (1/3 chacun, FIXE a priori — PAS optimise). Le composite est la somme.

## Vol-targeting + levier
- sigma_realisee(t) = vol annualisee (sqrt(252)) du rendement du composite sur 30 jours (et aussi sur 60j, pour la robustesse).
- levier L(t) = clamp(sigma_cible / sigma_realisee(t), 0.33, 2.0).
- rendement final(t+1) = L(t) x rendement_composite(t+1).

## Frais (a soustraire, pas a ignorer)
